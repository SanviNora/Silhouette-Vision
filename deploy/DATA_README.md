# Silhouette Vision: data bundle

Data for the Silhouette Vision app (https://github.com/SanviNora/Silhouette-Vision,
live at https://silhouette-vision.streamlit.app), built by `scripts/10_build_bundle.py`. Same
layout as the project's `data/` and `artifacts/`; thumbnails are packed in `archives/`.

| Content | Source and license |
|---|---|
| 11,999 products (2026): thumbnails, titles, brands | ZooClaw-Fashion evaluation set, SerendipityOne, **CC BY-NC 4.0** |
| 31,936 donated garments (2022–24): thumbnails, labels | Second-Hand Fashion Dataset, Nauman et al., RISE, Wargön Innovation and Myrorna (doi:10.5281/zenodo.13788681), CC BY 4.0 |
| 1,048 products (2025): thumbnails, categories | LookBench studio gallery, SerendipityOne, Apache-2.0 |
| 6,064 shoes, boots and sandals (c. 2019–21) | Amazon Berkeley Objects, Collins et al., CVPR 2022, CC BY 4.0 |
| 5,355 product thumbnails, embeddings, demand model | Visuelle 2.0, Skenderi et al., CVPR Workshops 2022, **CC BY-NC-SA 4.0** |
| Embeddings, attribute predictions, style clusters, trained heads and calibrators | Derived by the project author |

Because it includes non-commercial share-alike material, the bundle as a whole is shared under
CC BY-NC-SA 4.0: non-commercial use, with attribution, and derivatives under the same license.
