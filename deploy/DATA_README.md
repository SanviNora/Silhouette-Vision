# Silhouette Vision: public demo bundle

Data files for the Silhouette Vision demo app (https://github.com/SanviNora/Silhouette-Vision),
built by `scripts/10_build_public.py`. Same layout as the project's `data/` and `artifacts/`.

| Content | Source and license |
|---|---|
| 41,906 product thumbnails (320 px), catalog rows, embeddings, predicted attributes | Fashion Product Images (Myntra) by Param Aggarwal, Kaggle, MIT |
| 5,355 product thumbnails (320 px), image embeddings, demand model | Visuelle 2.0, Skenderi et al., "The multi-modal universe of fast-fashion: the Visuelle 2.0 benchmark", CVPR Workshops 2022, **CC BY-NC-SA 4.0** |
| Style-cluster aggregates and anonymous 2-D map positions | Derived from a 2019 Farfetch listings snapshot; no listings, prices or images included |
| Attribute heads, calibrators | Trained by the project author |

Because it includes Visuelle 2.0 material, this bundle as a whole is shared under
CC BY-NC-SA 4.0: non-commercial use, with attribution, and derivatives under the same license.
